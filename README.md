# Count-In

악보 PDF와 유튜브 반주를 함께 재생하는 연습 도구.
카운트다운 뒤 반주가 시작되고, **페이지별로 지정해둔 시각에 맞춰 악보가 자동으로 넘어간다.**
반주를 멈추면 악보도 멈추고, 되감으면 악보도 따라간다. (합창·악기 연습용)

`delayed-play.html`(카운트다운 유튜브 재생) + `pdf-autoflip.html`(PDF 자동 넘김)을 React로 합친 것.

## 로컬 실행

```bash
npm install
npm run dev        # http://127.0.0.1:5173 자동 오픈
```

> ⚠️ 폴더 이름은 반드시 영문(ASCII)으로. macOS에서 한글 폴더명은 유니코드 정규화(NFD)
> 문제로 Vite가 파일 경로를 못 찾는다.

## 사용법

1. 유튜브 반주 링크 붙여넣기 → 악보 PDF 불러오기
2. **넘김 방식**을 `쪽마다 시각 지정`으로 두고, 각 쪽을 넘길 시각을 `0:45`, `1:40`처럼 입력
   - 또는 `시작`을 눌러 반주를 들으며 **🎯 지금 넘김** 버튼(또는 키보드 `M`)으로 그 순간을 찍어 저장
   - 입력한 타이밍은 브라우저에 저장돼 다음에도 그대로 (영상+페이지수 기준)
3. `시작` → 카운트다운 후 반주 시작 + 악보 자동 넘김

단축키: `Space` 시작/일시정지 · `←/→` 이전·다음 쪽(재생 중엔 반주도 함께 이동) · `M` 지금 넘김 기록 · `Esc` 처음으로

넘김 방식 3가지: `쪽마다 시각 지정`(기본) / `일정 간격`(N초마다) / `곡 길이 균등`(전체 길이를 쪽 수로 균등 분배)

## Vercel 배포

Vite 프로젝트라 Vercel이 자동 인식한다. 이 폴더를 git 저장소로 올린 뒤:

- Framework Preset: **Vite** (자동 감지)
- Build Command: `npm run build`
- Output Directory: `dist`

별도 설정 파일 없이 그대로 배포된다. (악보 파일은 브라우저 안에서만 열리고 서버로 업로드되지 않는다.)
